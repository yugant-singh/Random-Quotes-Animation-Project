### Random Quotes Animation Project

# This project was created as a task assigned by Trainer: Sarthak Sharma from Sheriyans Coding School. The aim is to display random motivational, inspirational, and funny quotes on the screen with smooth animations.

# Objective

Create a webpage where each button click shows a random quote at a random position with fade-in, stay-visible, rise, rotation, and fade-out effects.

# Features

* Random quotes from a list of 20
* Random on-screen positioning
* Controlled scale values for readability
* Smooth CSS animation
* Automatic removal of old quotes

# Technologies Used

* HTML
* CSS
* JavaScript

# How It Works

* A quote is picked randomly from an array.
* A new element is created and positioned randomly.
* A CSS animation class is applied.
* The quote stays visible for a short duration, then fades and is removed.
